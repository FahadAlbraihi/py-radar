# رادار بايثون 🐍

تطبيق ويب يجمع محتوى **برمجة بايثون بالعربي والإنجليزي** من مصادر متعددة في مكان واحد،
ويحدّث نفسه **يومياً**. يعمل من متصفح الآيفون ويمكن إضافته للشاشة الرئيسية ليصبح كأي تطبيق.

---

## التشغيل على الآيفون

### الطريقة الأسهل (من نفس شبكة الواي فاي)

على الكمبيوتر:

```bash
python py-radar/serve.py
```

سيطبع رابطين. افتح الرابط الثاني (`http://192.168.x.x:8000/`) من **Safari** على الآيفون،
ثم: زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

> `serve.py` يقدّم الملفات ويعمل كذلك كبروكسي، وهو أثبت طريقة لجلب المصادر العربية.

### الطريقة الدائمة (يعمل من أي مكان)

ارفع مجلد `py-radar` على **GitHub Pages** (أو Netlify / Cloudflare Pages):

1. أنشئ مستودعاً وارفع الملفات فيه.
2. `Settings ← Pages ← Deploy from branch ← main / (root)`.
3. افتح الرابط من الآيفون وأضِفه للشاشة الرئيسية.

عندها يتولى ملف `.github/workflows/daily.yml` تشغيل `build_feed.py` **كل يوم الساعة ٦ صباحاً
بتوقيت مكة**، فيحدّث `data/feed.json` تلقائياً ويقرأه التطبيق مباشرة بدون بروكسي.

## كيف يتم التحديث؟

| الطبقة | متى تعمل |
|---|---|
| جلب مباشر من المصادر | عند كل فتح للتطبيق إذا مضى أكثر من ٦ ساعات، أو عند تغيّر اليوم |
| زر التحديث / السحب للأسفل | فوراً عند الطلب |
| `build_feed.py` عبر GitHub Actions | مرة يومياً (للنسخة المستضافة) |

المحتوى يُخزَّن في ذاكرة المتصفح، فيظهر فوراً عند الفتح حتى بدون إنترنت.

## المصادر

**عربي** — بحث أخبار جوجل و Bing يغطي مواقع عربية كثيرة (أكاديمية حسوب، أراجيك، مواقع
الجامعات، مواقع تقنية) بالإضافة إلى دروس وفيديوهات يوتيوب العربية.

**إنجليزي** — Hacker News · DEV.to · Stack Overflow · GitHub · PyPI · Real Python ·
Planet Python · Python Blog · r/Python · r/learnpython.

يُطبَّق فلتر يستبعد ما ليس عن البرمجة (أخبار ثعابين البايثون والسيارات مثلاً)،
وحدٌّ أقصى لكل مصدر حتى لا يطغى مصدر واحد.

## الملفات

```
py-radar/
├── index.html          الواجهة
├── styles.css          التنسيق (عربي RTL + وضع ليلي + مقاسات الآيفون)
├── app.js              الجلب والفلترة والعرض
├── sw.js               العمل بدون إنترنت
├── manifest.webmanifest
├── serve.py            خادم محلي + بروكسي CORS
├── build_feed.py       يبني data/feed.json (اللقطة اليومية)
├── make_icons.py       يولّد الأيقونات
└── .github/workflows/daily.yml    التحديث اليومي الآلي
```

كل شيء بمكتبات بايثون القياسية فقط — لا تثبيت ولا اعتمادات خارجية.

## المميزات

- بحث فوري داخل كل المحتوى
- فلترة: عربي / إنجليزي / حسب المصدر
- حفظ المقالات (★) لقراءتها لاحقاً
- وضع ليلي تلقائي حسب إعداد الآيفون
- السحب للأسفل = تحديث
- يعمل بملء الشاشة بعد إضافته للشاشة الرئيسية

## تخصيص

لإضافة مصدر جديد: أضِف رابط RSS في مصفوفة `SOURCES` داخل [app.js](app.js)
وفي `FEEDS` داخل [build_feed.py](build_feed.py). ولإضافة نطاق للبروكسي المحلي،
أضِفه إلى `ALLOWED_HOSTS` في [serve.py](serve.py).
