# رادار البرمجة 🐍

تطبيق ويب يجمع محتوى برمجياً **بالعربي والإنجليزي** من مصادر متعددة، ويصنّفه حسب
**لغة البرمجة والمستوى ونوع المحتوى**، ويحدّث نفسه **يومياً**.
يعمل من متصفح الآيفون ويمكن إضافته للشاشة الرئيسية ليصبح كأي تطبيق.

**التطبيق:** https://fahadalbraihi.github.io/py-radar/

---

## المسارات المدعومة

بايثون · جافاسكربت · SQL · C/C++ · جافا · Go · Rust · **🛡 أمن سيبراني** · Bash/Shell

اختر مساراً أو أكثر من الشريط العلوي؛ يمكن تفعيل أكثر من مسار معاً — مثلاً
**بايثون + الأمن السيبراني** لمتابعة التخصصين بالتوازي.

مسار الأمن السيبراني له مصادره الخاصة: r/netsec و r/HowToHack، ومقالات Medium،
وبحث عربي عن اختبار الاختراق وكالي لينكس، وبودكاست Darknet Diaries.

## مزايا التعلّم

| الميزة | ماذا تفعل |
|---|---|
| **خارطة التعلّم** | ١٧ مرحلة (١٢ برمجية + ٥ أمنية) تكتمل بما تضعه في «أنهيته»، واضغط أي مرحلة لتصفية المحتوى عليها |
| **الستريك اليومي** | عدّاد أيام متتالية يتصفّر عند انقطاع يوم |
| **إحصاءات أسبوعية** | كم أنهيت هذا الأسبوع، كم ينتظرك، كم موضوعاً غطّيت |
| **البحث بالكود** | الصق مقطع كود فتُستخرج منه المكتبات والدوال ويُبحث عنها (مثال: `import socket` ← socket, requests, async) |
| **بحث سريع جاهز** | استعلامات معدّة مثل «مشروع بايثون للأمن السيبراني» و«أسئلة مقابلات بايثون» |
| **تصدير القائمة** | يحفظ مكتبتك في ملف نصي وينسخها إلى الحافظة |
| **لافتة العودة** | بعد غياب يومين فأكثر تخبرك بعدد الجديد |

## الفلاتر

| الفلتر | الخيارات |
|---|---|
| لغة المحتوى | الكل · عربي · إنجليزي · مترجم/بالعربي |
| المستوى | مبتدئ · متوسط · متقدم |
| نوع المحتوى | دورة كاملة · شرح · مشروع · تحدي · مقابلة عمل · أداة/خبر |
| الترتيب | الأحدث · الأكثر تفاعلاً · الأكثر مشاهدة · الأعلى تقييماً |
| المصدر | حسب المصادر المتاحة |

التصنيف يتم بقواعد لغوية على العنوان والوصف (عربية وإنجليزية معاً) داخل
[`app.js`](app.js) — لا يحتاج أي خدمة خارجية.

## البحث في يوتيوب

اكتب ما تريد في مربع البحث ثم اضغط زر **«ابحث في يوتيوب»** (أو Enter). يبحث التطبيق
مباشرة في يوتيوب **بالعربي والإنجليزي معاً ولكل لغات البرمجة**، بلا مفتاح API،
ويعرض النتائج وحدها حتى تلغي البحث من الشارة أعلى القائمة.

لتفادي النتائج الخاطئة (أسماء مثل Rust و Java و Go تشترك مع ألعاب) يُضاف سياق
برمجي إلى الاستعلام نفسه، ثم تُرشَّح النتائج بإشارة تعليمية برمجية مع استبعاد
محتوى الألعاب — إلا ما كان عن *برمجة* لعبة.

## مسار التعلّم

اختر مرحلتك الحالية (الأساسيات، الحلقات، الدوال، OOP، الويب، البيانات…) فيُرفع
المحتوى المطابق لها إلى أعلى القائمة، أو فعّل **«اعرض هذه المرحلة فقط»** لحصر النتائج.

## مكتبتي

لكل عنصر ثلاث حالات: **★ محفوظ**، **⏱ أشاهده لاحقاً**، **✓ أنهيته**.
لوحة «مكتبتي» تعرض تقدّمك: كم أنهيت، كم أنهيت هذا الأسبوع، وكم بانتظارك.

كذلك تظهر شارة **«جديد»** على كل ما نُشر بعد آخر زيارة لك.

## التشغيل على الآيفون

### من الرابط المنشور

افتح https://fahadalbraihi.github.io/py-radar/ من **Safari** ← زر المشاركة ←
**إضافة إلى الشاشة الرئيسية**.

### محلياً (نفس شبكة الواي فاي)

```bash
python serve.py
```

يطبع رابطاً مثل `http://192.168.x.x:8000/` تفتحه من الآيفون.
`serve.py` يقدّم الملفات ويعمل كذلك كبروكسي CORS، وهو أثبت طريقة لجلب المصادر العربية محلياً.

## كيف يتم التحديث؟

| الطبقة | متى تعمل |
|---|---|
| جلب مباشر من المصادر | عند كل فتح إذا مضت أكثر من ٦ ساعات أو تغيّر اليوم |
| زر التحديث / السحب للأسفل | فوراً عند الطلب |
| `build_feed.py` عبر GitHub Actions | مرة يومياً، ملف لكل لغة في `data/` |

البناء اليومي **يضمّ محتوى الملف السابق** قبل الكتابة، فتعثّر شبكي في تشغيل واحد
لا يمسح ما نُشر. كما يُحجز للمحتوى العربي حدٌّ أدنى من المساحة (`AR_QUOTA`) حتى لا
تزحمه المصادر الإنجليزية الغزيرة.

## المصادر

**عربي** — بحث أخبار جوجل و Bing (يغطي مواقع عربية كثيرة: أكاديمية حسوب، أراجيك،
مواقع الجامعات والمواقع التقنية) بالإضافة إلى دروس وفيديوهات يوتيوب العربية.

**إنجليزي** — Hacker News · DEV.to · Stack Overflow · GitHub · PyPI · Real Python ·
Planet Python · Reddit (‏r/Python، r/learnpython، ونظائرها لكل لغة).

يُطبَّق فلتر يستبعد ما ليس عن البرمجة (أخبار ثعابين البايثون والسيارات مثلاً)،
وحدٌّ أقصى لكل مصدر حتى لا يطغى مصدر واحد.

### قنوات يوتيوب

تغذية RSS لقناة يوتيوب تحمل **عدد المشاهدات والتقييم والصورة المصغّرة** بدون أي
مفتاح API — وهي مصدر بيانات الترتيب حسب المشاهدات والتقييم.
تُضاف القنوات بأسمائها في `CHANNEL_HANDLES` داخل [`build_feed.py`](build_feed.py)،
ويتحقق السكربت تلقائياً من أن القناة تنشر محتوى برمجياً فعلاً قبل اعتمادها
(القنوات المرفوضة تُسجَّل في `data/channels.json` فلا يُعاد فحصها).

## ما لا يفعله التطبيق (وأسبابه)

- **مدة الفيديو بالدقائق**: لا توفّرها تغذيات RSS؛ تحتاج YouTube Data API بمفتاح،
  والمفتاح على موقع عام مكشوف. البديل المتاح: نوع المحتوى **«دورة كاملة»** مقابل درس مفرد.
- **تنبيهات فورية (Push)**: تحتاج خادماً يرسل الإشعارات ومفاتيح VAPID، ولا تعمل على
  iOS إلا بعد تثبيت التطبيق على الشاشة الرئيسية. البديل المطبَّق: شارة **«جديد»**
  وعدّاد الجديد منذ آخر زيارة.

## الملفات

```
py-radar/
├── index.html          الواجهة
├── styles.css          التنسيق (عربي RTL + وضع ليلي + مقاسات الآيفون)
├── app.js              الجلب والتصنيف والفلترة والعرض
├── sw.js               العمل بدون إنترنت
├── manifest.webmanifest
├── serve.py            خادم محلي + بروكسي CORS
├── build_feed.py       يبني data/feed-<لغة>.json يومياً
├── make_icons.py       يولّد الأيقونات
├── publish.ps1         الرفع على GitHub وتفعيل Pages
└── .github/workflows/daily.yml
```

كل شيء بمكتبات بايثون القياسية فقط — لا تثبيت ولا اعتمادات خارجية.

## تخصيص

- **لغة برمجة جديدة**: أضِف مدخلاً في `TECHS` داخل [`app.js`](app.js) وفي `TECHS`
  داخل [`build_feed.py`](build_feed.py).
- **مرحلة تعلّم جديدة**: أضِفها إلى `STAGES` في [`app.js`](app.js).
- **قاعدة تصنيف**: عدّل `LEVEL_RE` أو `KIND_RE` في [`app.js`](app.js).
- **نطاق جديد للبروكسي المحلي**: أضِفه إلى `ALLOWED_HOSTS` في [`serve.py`](serve.py).
